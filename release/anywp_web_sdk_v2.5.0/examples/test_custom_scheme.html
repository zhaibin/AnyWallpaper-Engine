🔐 AnyWP Custom Scheme Test

📋 Protocol Info

Protocol: anywp://

Purpose: Encrypted image and video loading

Algorithm: XOR (Key: 0x5A, First 64 bytes)

Format: anywp://file?path={absolute_path}

🖼️ Example: Encrypted Image

To test this feature:

  1. Use Flutter to encrypt an image file
  2. Note the encrypted file path
  3. Load it using anywp://file?path=/path/to/encrypted.dat

🎥 Example: Encrypted Video

Videos work the same way as images!

anywp://file?path=/path/to/encrypted_video.dat

🧪 How to Test

Step 1: Use Flutter to encrypt a test file:

await AnyWPEngine.encryptFile(
  sourcePath: '/path/to/image.jpg',
  destPath: '/tmp/test_encrypted_image.dat'
);

Step 2: Reload this page to see the encrypted image

Step 3: Check browser console for logs
