🔧 技术细节

  • 协议格式：anywp://file?path={完整路径}
  • 加密算法：XOR (Key: 0x5A, 前64字节)
  • 路径控制：开发者自定义，本次使用桌面测试目录
  • 安全验证：绝对路径、防路径遍历、非法字符检查
  • MIME 检测：自动识别文件类型（JPEG、PNG、MP4 等）
