feat(version): 统一版本号管理 - 自动从 pubspec.yaml 生成 C++ 版本头文件

核心改进：
1. **单一数据源** - 版本号仅在 pubspec.yaml 中定义
2. **自动生成** - CMake 自动从 pubspec.yaml 读取并生成 windows/version.h
3. **零维护成本** - C++ 代码中的版本常量自动同步
4. **完全一致性** - Plugin版本、SDK版本、Package版本始终保持一致

实施细节：
- 新增 windows/version.h.in 模板文件
- CMake 在配置时自动生成 windows/version.h
- 更新 anywp_engine_plugin.cpp 使用新的版本头文件
- 更新 .gitignore 忽略自动生成的 version.h
- 更新 CHANGELOG_CN.md 和 .cursorrules 文档

技术优势：
✓ 彻底解决版本号不一致问题
✓ 简化发版流程（只需修改一处）
✓ 避免人为错误
✓ 自动化程度更高

开发者影响：
- 发版时只需更新 pubspec.yaml 中的版本号
- 无需手动修改 C++ 代码中的版本常量
- windows/version.h 会被自动生成（已添加到 .gitignore）

文件修改：
- windows/version.h.in (新增)
- windows/CMakeLists.txt (版本号自动生成)
- windows/anywp_engine_plugin.cpp (使用 version.h)
- .gitignore (忽略 windows/version.h)
- .cursorrules (更新发版流程文档)
- CHANGELOG_CN.md (添加版本管理说明)
