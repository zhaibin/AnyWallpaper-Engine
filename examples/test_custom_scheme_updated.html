Developer-Controlled Path Version (v2.1.10+)

📋 新架构特性

  • ✅ 开发者控制路径：不再硬编码缓存位置
  • ✅ 通用化设计：引擎只负责加解密算法
  • ✅ 路径安全验证：防止路径遍历攻击
  • ✅ 完善异常处理：文件不存在、解密失败等
  • ✅ 灵活的协议格式：anywp://file?path={完整路径}

🚀 使用示例

1. 加密文件（Flutter/Dart）

```dart // 开发者自定义缓存位置 final customCachePath = 'D:/MyWallpaperApp/cache'; // 加密文件 bool success = await AnyWPEngine.encryptFile( sourcePath: 'C:/my_wallpapers/image.jpg', destPath: '$customCachePath/image_001.encrypted', ); ```

2. 在 HTML 中使用

```html <!-- 直接使用完整路径 --> <img src="anywp://file?path=D:/MyWallpaperApp/cache/image_001.encrypted" /> <!-- JavaScript 动态加载 --> <script> const cachePath = 'D:/MyWallpaperApp/cache'; const imageUrl = `anywp://file?path=${cachePath}/image_001.encrypted`; document.getElementById('myImage').src = imageUrl; </script> ```

3. 路径管理建议

  • 使用 绝对路径（如 C:/path/to/file）
  • 避免使用 ..（路径遍历）
  • 推荐使用 %APPDATA%、%LOCALAPPDATA% 或自定义目录
  • 为不同应用设置不同的缓存目录，避免冲突
